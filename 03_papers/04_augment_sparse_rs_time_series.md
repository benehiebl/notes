
# Title: 
Augmentation strategies for irregular and sparsely sampled observations in remote sensing time series data

> [!Motivation]
> Label sparcity is a major problem in supervised learning tasks, when using large deep learning models. Data augmentation is a common way to prevent overfitting under these settings. Proper investigations into augmentation techniques for sparse and irregular remote sensing time series on a pixel level are lacking.

> [!What research questions will be answered?]
> - What types of techniques perform best against generalization?
> - Which type of model is more robust (TimeCNN or TimeTransformer)?
> 

> [!What will be done?]
> Testing several augmentation techniques in a cross validation experiment on Sentinel-2 time series point data. Additionally it will be tested which model type is more robust to wrong or no augmenation and still generalizes well.

> [!What are the expected results?]
> - CNN more robust, but outperformed by TST
> - special techniques necessary for sparse time series: shifting and adding noise
